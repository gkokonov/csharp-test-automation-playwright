# Repository review checklist

Read root AGENTS.md and docs/AGENT_SUPPORT.md for instruction/host changes.
Check single policy ownership, valid links/anchors, root size, adapter discovery,
tool permissions, local execution, and consistent scope routing. File presence
does not prove host activation. Preserve architecture/specification reference owners.
For build/configuration changes inspect dependency direction, analyzer settings,
secrets and environment ownership, generated-file exclusions and compatibility.
Do not report accepted exceptions as newly introduced defects.
Apply .agents/review/REVIEW.md for evidence, scope, and reporting.
